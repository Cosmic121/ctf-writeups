# Room: MAC Spoofing

## Objective:
- To understand how MAC addresses are spoofed to gain access or sniff transmitted data.

## Steps:
- Spoofing the MAC address of a system to match another authorized system ,that has access to the WiFi

## Result:
The Unauthoeized MAC address was able to access WiFi upon spoofing its MAC address.

## What i Learned:
- Certain MAC addresses can be blocked by configurng a firewall
- However, the MAC address can be spoofed to bypass this firewall
- Weak Configuration can cause unauthorized access
