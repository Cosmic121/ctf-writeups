# Room: Network Topologies (TryHackMe)

## Objective
Understand different network topologies and their weaknesses.

## Overview
This room explores how different network topologies transmit data, how they function, and their potential vulnerabilities.

## Topologies & Analysis

### 1. Ring Topology
- Data travels in a circular path between devices.
- A break in any cable or node disrupts the entire network.

### 2. Bus Topology
- All devices share a single backbone cable.
- High traffic can overload the network, leading to performance issues or failure.

### 3. Star Topology
- All devices are connected to a central hub or switch.
- If the central device fails, the entire network becomes unavailable.

## Key Takeaways
- Each topology has a unique method of data transmission.
- Every topology has specific weaknesses that can be exploited.
- Network design plays a critical role in security and reliability.
